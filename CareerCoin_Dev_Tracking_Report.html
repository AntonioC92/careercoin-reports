2. Issue 1 — WooCommerce Events Missing from dataLayer

No ecommerce events pushed on add to cart
Cart and checkout activity is invisible to all tracking platforms
HIGH
What I observed
Adding a product to cart worked correctly on the UX side — the product was added and the confirmation appeared. However, checking the dataLayer immediately after showed no ecommerce event had been pushed.

In GTM Preview, the only events visible were:
gtm.js gtm.dom gtm.load form_start form_submit
The dataLayer contained only:
{ event: "gtm.load" }
What this means
  • No add_to_cart event in the dataLayer
  • No ecommerce object with product name, price or value
  • GTM has nothing to trigger — no conversion fires to GA4, Google Ads or Meta
Root cause
WooCommerce does not push ecommerce events to the dataLayer by default. It needs a dedicated plugin to bridge between WooCommerce actions and GTM's dataLayer. Without this bridge, all cart and checkout activity is invisible to any tracking tool.
Fix — Install GTM4WP plugin
Recommended plugin
GTM4WP — Google Tag Manager for WordPress
wordpress.org/plugins/duracelltomi-google-tag-manager

Once configured, the dataLayer will contain structured events like this on add to cart:
dataLayer.push({ event: "add_to_cart", ecommerce: { currency: "EUR", value: 9, items: [{ item_name: "CareerSearch Agent", item_id: "456", price: 9 }] } });
GTM trigger to use: Custom Event · event name = add_to_cart
Configuration steps after install
  1. Install and activate GTM4WP from the WordPress plugin directory
  2. Go to Settings → Google Tag Manager, connect container ID: GTM-MG5RK4Q
  3. Under the Integration tab, enable WooCommerce integration
  4. Enable Enhanced Ecommerce data (GA4-compatible)
  5. Enable dataLayer events: view_item add_to_cart begin_checkout purchase
  6. Save settings and verify in GTM Preview
Expected result after fix
GTM Preview will show these events at the correct moments:
view_item — when a product page is loaded add_to_cart — when a product is added to cart begin_checkout — when the checkout page is reached purchase — when the order confirmation page loads
What becomes possible: GA4 ecommerce reports with product-level data · Google Ads conversion value tracking · Meta AddToCart and Purchase events with correct value

3. Tracking Upload CV — Richiesta implementazione

IT
Nessun evento cv_uploaded presente nel dataLayer
GTM non può tracciare il completamento dell'upload del CV
HIGH
Test eseguiti
  • Test manuale di caricamento CV nella sezione profilo utente
  • Verifica del dataLayer tramite Console del browser
  • Verifica tramite Google Tag Manager Preview Mode
  • Spy su dataLayer.push durante tutta la sequenza di upload
Risultato del test
Durante l'upload del CV non viene generato nessun evento nel dataLayer. Gli unici eventi presenti sono quelli standard di GTM:
gtm.js gtm.dom gtm.load form_start form_submit
Non compare nessun evento applicativo legato all'upload. GTM non sa quando un CV viene caricato con successo — nessuna conversione viene inviata a GA4, Google Ads o Meta.
Implementazione richiesta
Push minimo richiesto
Nel punto in cui il sistema conferma il caricamento corretto aggiungere:
window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: "cv_uploaded" });
Versione consigliata (con parametri)
Con parametri aggiuntivi utili per l'analisi:
window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: "cv_uploaded", file_type: "pdf", file_name: "example_cv.pdf" });
Dove inserire il push
Il push deve avvenire solo dopo conferma di successo. Punti di integrazione validi:
  1. Dopo il completamento della funzione backend che salva il file (PHP / WordPress upload handler)
  2. Nella risposta success della chiamata AJAX che gestisce l'upload
  3. Nel momento in cui il sistema salva l'URL del CV nel profilo utente
Non deve attivarsi su
  • Click del bottone upload
  • Apertura della pagina profilo
  • Selezione del file prima del caricamento

Deve attivarsi solo quando il file è stato effettivamente salvato sul server.
Verifica via Console del browser
  1. Aprire la Console del browser
  2. Caricare un CV nella sezione profilo
  3. Verificare la presenza del push:
dataLayer.push({ event: "cv_uploaded" })
Verifica via GTM Preview
Aprire GTM Preview, caricare un CV e verificare che nella lista eventi compaia:
cv_uploaded
Utilizzo lato GTM — già pronto
Una volta che l'evento è presente nel dataLayer, il trigger e i tag su GTM sono già configurati e pronti. Il trigger Custom Event su cv_uploaded attiverà automaticamente: GA4 Event cv_uploaded · Google Ads conversion · Meta Pixel custom event
✅
