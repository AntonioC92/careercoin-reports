2. Issue 1: WooCommerce Events Missing from dataLayer

No ecommerce events pushed on add to cart
HIGH
What I observed
I added a product to cart. The action completed on the UX side, but checking the dataLayer immediately after showed no ecommerce event had been pushed.

In GTM Preview, the only events visible were:
gtm.js gtm.dom gtm.load form_start form_submit
The dataLayer contained only:
{ event: "gtm.load" }
What this means
  • No add_to_cart event in the dataLayer
  • No ecommerce object with product name, price or value
  • GTM has nothing to trigger. No conversion fires to GA4, Google Ads or Meta
Root cause
WooCommerce does not push ecommerce events to the dataLayer by default. It needs a dedicated plugin to bridge between WooCommerce actions and GTM's dataLayer. Without this bridge, all cart and checkout activity is invisible to any tracking tool.
Fix: Install GTM4WP plugin
Recommended plugin
GTM4WP - Google Tag Manager for WordPress
wordpress.org/plugins/duracelltomi-google-tag-manager

This plugin pushes standard WooCommerce ecommerce events to the dataLayer automatically. After installation, the dataLayer will contain structured objects on every cart action:
dataLayer.push({ event: "add_to_cart", ecommerce: { currency: "EUR", value: 9, items: [{ item_name: "CareerSearch Agent", item_id: "456", price: 9 }] } });
GTM trigger: Custom Event, event name = add_to_cart
Configuration steps after install
  1. Install and activate GTM4WP from the WordPress plugin directory
  2. Go to Settings → Google Tag Manager, connect container ID: GTM-MG5RK4Q
  3. Under the Integration tab, enable WooCommerce integration
  4. Enable Enhanced Ecommerce data (GA4-compatible)
  5. Enable dataLayer events: view_item add_to_cart begin_checkout purchase
  6. Save settings and verify in GTM Preview
Expected result after fix
GTM Preview will show these events at the correct moments:
view_item -- when a product page is loaded add_to_cart -- when a product is added to cart begin_checkout -- when the checkout page is reached purchase -- when the order confirmation page loads
GA4 ecommerce reports, Google Ads conversion value tracking, and Meta AddToCart/Purchase events will all work correctly.

3. CV Upload Tracking: Implementation Request

No cv_uploaded event in the dataLayer
GTM cannot track when a CV is successfully uploaded
HIGH
Tests performed
  • Manual CV upload test in the user profile section
  • dataLayer inspection via browser Console
  • Verification via Google Tag Manager Preview Mode
  • Monitoring dataLayer.push throughout the upload sequence
Test result
No event is pushed to the dataLayer during the CV upload. The only events present are the standard GTM ones:
gtm.js gtm.dom gtm.load form_start form_submit
No application-level event related to the upload appears. GTM has no way to know when a CV has been saved successfully, so no conversion is sent to GA4, Google Ads or Meta.
Required implementation
Minimum push required
Add the following push where the system confirms the file has been saved:
window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: "cv_uploaded" });
Recommended version (with parameters)
Include file metadata for better analysis:
window.dataLayer = window.dataLayer || []; window.dataLayer.push({ event: "cv_uploaded", file_type: "pdf", file_name: "example_cv.pdf" });
Where to add the push
The push must fire only after a confirmed successful save. Valid integration points:
  1. After the backend function that saves the file completes (PHP / WordPress upload handler)
  2. In the success callback of the AJAX call that handles the upload
  3. When the system saves the CV URL to the user profile
Must NOT fire on
  • Upload button click
  • Profile page load
  • File selection before upload

Only fire when the file has actually been saved on the server.
Verify via browser Console
  1. Open the browser Console
  2. Upload a CV in the profile section
  3. Check that the following push appears:
dataLayer.push({ event: "cv_uploaded" })
Verify via GTM Preview
Open GTM Preview, upload a CV, and confirm this event appears in the event list:
cv_uploaded
GTM side: already configured
Once the event is present in the dataLayer, the GTM trigger and tags are already set up and ready. The Custom Event trigger on cv_uploaded will automatically fire: GA4 Event cv_uploaded, Google Ads conversion, Meta Pixel custom event.
✅
